# サンプルデータ

すべて架空のデータです。製造向けは、CSV・Excelを読み込んで可視化するアプリの
動作確認に使えます。

| ファイル | 形式 | 用途 | 確認できること |
|---|---|---|---|
| `01_production_results.csv` | CSV / UTF-8 BOM | 実績推移・歩留 | 1時間×8設備の計画数・生産数・良品数・不良数。L2-02は不良率が高め、直の切り替わり時刻も高め |
| `02_defect_records_sjis.csv` | CSV / Shift_JIS | パレート図 | 不良1件ごとの記録。Shift_JISの読み込み、空欄（記録者）の扱い。記録者は「テスト記録者01」等の連番 |
| `03_quality_measurements.xlsx` | Excel | 管理図 | 5項目の測定値と上下限。先頭にタイトル行あり。「外径」は後半で上にずれていき、まれに外れ値がある |
| `04_equipment_status.tsv` | TSV / UTF-8 | ガントチャート | 設備ごとの状態区間（稼働・段取り・停止・故障など）と開始・終了日時 |
| `05_production_plan.xlsx` | Excel（2シート） | ガント／計画比 | 計画と実績の開始・終了時刻、数量。9/26以降は未着手で実績欄が空。2枚目は品番マスター |


## バックオフィス向け

「データを入力して管理・共有したい」「手元のデータを処理したい」タイプのアプリ（間接部門の台帳・
予定・問い合わせ・AI処理）の動作確認用。架空の会社「株式会社テストデータ（架空）」の2026年度（4/1〜9/26）の業務データ。
会社名・人名は「テスト取引先0001」「テスト社員01」「先方担当者0001」のような連番で、実在しない。
列名は、アプリがサンプルから役割（取引先・金額・期日・担当者・伝票番号など）を推定できる名前にしてある。

| ファイル | 形式 | 用途 | 確認できること |
|---|---|---|---|
| `11_customers.csv` | CSV / UTF-8 BOM | 台帳・一覧管理 | 顧客500社＋重複登録6件。会社名の表記ゆれ（株式会社／(株)／㈱）、電話・メールの空欄、取引区分・与信限度額 |
| `12_deals.xlsx` | Excel（2シート） | 予定・進捗、集計 | 案件1000件のステージ・確度・見込金額・受注予定日。2枚目は担当者マスター（部署・内線） |
| `13_invoices_sjis.csv` | CSV / Shift_JIS | 集計・入金管理 | 請求1500件。税率（10%・一部8%）、支払期日と入金日、入金状況（入金済・未入金・一部入金・期日超過） |
| `14_expenses.xlsx` | Excel | 承認フロー、集計 | 経費精算1500件。先頭にタイトル行あり。部署・科目別の金額、承認状況（申請中・承認済・差戻し・精算済） |
| `15_assets.tsv` | TSV / UTF-8 | 台帳・貸出管理 | 備品400件。取得金額・耐用年数、状態（使用中・貸出中・保管・修理中・廃棄予定）、貸出期限切れ |
| `16_inquiries.csv` | CSV / UTF-8 | 問い合わせ・タスク管理 | 1200件。本文に改行・カンマを含む（引用符付き）。優先度ごとの期日、状態、未割り当て |
| `17_tasks.xlsx` | Excel | 予定・進捗、ガント | 案件80件×7工程の予定と実績、進捗率（%表示）。未着手・作業中・遅延・完了 |
| `pdf/invoice_*.pdf` | PDF | AI処理（読み取り・登録） | 請求書5件。中身は `13_invoices_sjis.csv` の同じ伝票番号の行と一致するので、読み取り結果を突き合わせられる |
| `pdf/quotation_*.pdf` | PDF | AI処理（読み取り・登録） | 見積書3件（品目3行・小計・消費税・合計・有効期限） |
